# Contributing
We welcome contributions from anyone. Please note that all participants of this project are expected to follow our [Code of Conduct](.github/CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.

## Pull requests
Pull requests are welcome. Please follow the existing code style, include tests when relevant, and update the documentation and [CHANGELOG.md](.github/CHANGELOG.md) if needed.

## Reporting issues
Please report bugs or request features via GitHub Issues.

## Questions
For questions, please open an issue or contact the project team at yanic.cardin@etud.polymtl.ca.
